# FleetOps Website v1.2.0

גרסה עדכנית של דף הנחיתה.

## מה השתנה
- אין הצגה פומבית של מספר הטלפון או כתובת המייל.
- כל כפתורי יצירת הקשר פותחים WhatsApp.
- טופס יצירת הקשר בונה הודעת WhatsApp אוטומטית עם:
  - שם
  - חברה
  - טלפון
  - תיאור הצורך
- אין שמירת פרטים באתר.
- נוספה התייחסות מפורשת לסופרמרקטים, רשתות, הזמנות מרובות שקיות ומשלוחים גדולים בעיר.
- הודגש כי השליחים הם עובדים שכירים של FleetOps.
- בפוטר מופיעה גרסת האתר: v1.2.0.
- זכויות שמורות: L.K Consulting.
