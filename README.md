## העלאה ל-GitHub Pages
1. צור Repository חדש ב-GitHub.
2. העלה אליו את כל תוכן התיקייה.
3. עבור ל-Settings > Pages.
4. תחת Build and deployment בחר Deploy from a branch.
5. בחר `main` ו-`/ (root)`.
6. שמור. בתוך כמה דקות GitHub יציג את כתובת האתר.

## עריכת טקסטים
כל תוכן האתר נמצא בתוך `index.html`.

## החלפת תמונות
החלף קבצים בתוך `assets/` והשאר את אותם שמות, או עדכן את הנתיב ב-`index.html`.
